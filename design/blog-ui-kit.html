Grid

Desktop is a 12-column CSS Grid inside a 1200px container with 24px gutters, so each column is 78px. Mobile is 4 columns with 16px side margins and 16px gutters (77.5px columns). Turn on Grid overlay in the toolbar to see it on the page layouts.

Spacing

Base-8. Every margin, padding and gap in the layouts is one of these tokens. The 4px half-step exists only for inline-code padding and the tightest icon nudges. Bars are drawn at 200%.

--s-0  4Inline code padding
--s-1  8Icon to label, pill and tag gaps, button gaps
--s-2 16Button and field padding, gaps inside cards
--s-3 24Card padding, grid gutter, paragraph gap
--s-4 32Featured card padding, gap between grid blocks
--s-6 48Section top padding, newsletter panel padding
--s-8 64Hero padding, footer top margin

Radius and elevation

Radius steps with the size of the container, so a card is rounder than the button inside it. Dark surfaces show elevation with a border highlight first and a shadow second.
