Creating forms manually is tedious: defining fields, configuring validation rules, setting up responsive layouts, and hooking up database schemas.

To streamline this workflow, I built **[AI Form Builder](https://forms.ragibshahrier.com/)**, a full-stack application that turns natural language prompts into complete, production-ready forms in seconds—complete with drag-and-drop customization and live response analytics.

***

## The Tech Stack

* **Frontend**: React 19, Vite, Tailwind CSS v4
* **Drag and Drop**: `@dnd-kit/core` & `@dnd-kit/sortable`
* **Form Management**: `react-hook-form` & `sonner` notifications
* **Backend**: Node.js & Express
* **AI Engine**: `@google/genai` (Google Gemini with multi-model fallback)
* **Database**: PostgreSQL (`pg`) with relational form schemas
* **Authentication**: JWT & `bcryptjs`
* **Data Visualization**: Recharts

***

## Core Architecture & Engineering Highlights

### 1. Resilient Prompt-to-Form Generation (Multi-Model Fallback)

Public AI APIs can occasionally hit rate limits (`429`) or temporary service unavailability (`503`). To ensure forms are generated reliably without user-facing failures, the backend uses a tiered multi-model fallback system:

```javascript title="services/gemini.service.js" {5-12}
// Fallback pipeline: primary flash model -> secondary pro/flash fallbacks
async function callWithFallback(prompt, schema) {
  const models = ["gemini-2.5-flash", "gemini-2.0-flash", "gemini-1.5-pro"];

  for (const model of models) {
    try {
      return await generateFormSchema(model, prompt, schema);
    } catch (err) {
      if (err.status === 429 || err.status === 503) {
        console.warn(`Model ${model} overloaded, falling back to next model...`);
        continue;
      }
      throw err;
    }
  }
}
```

The model generates structured JSON conforming strictly to our supported field primitives (`text`, `number`, `select`, `multiselect`, `date`, `rating`, and `file`), automatically generating sensible validation constraints like regex patterns and required flags.

### 2. Smooth Drag-and-Drop with `@dnd-kit`

Once generated, users can visually reorder fields, edit labels, or add custom questions. Using `@dnd-kit/sortable`, field reordering runs on hardware-accelerated transforms without layout jank:

* Keyboard accessible navigation for screen reader support.
* Constrained vertical dragging axis to prevent erratic element displacement.
* Optimistic UI updates with instantaneous state reconciliation.

### 3. Submission Analytics & Visual Insights

Beyond form creation, the platform collects submissions and renders live visual breakdowns using Recharts:

* Real-time submission counter and completion rates.
* Categorical breakdowns with interactive bar and pie charts.
* Export capabilities for CSV and JSON datasets.
